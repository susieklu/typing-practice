create typing practice activity for beginner typers
tell the student what to type, give them a chance to submit, then assess their work. determine the number of mistypes or deleted letters and provide an accuracy score 

Here's a suggested plan:

Prohibit pasting into the typing box.

Description of Desired Typing Practice Behavior:
The interface displays a sequence of letters or words the child needs to type.
As the child presses each key:
If the typed letter matches the expected letter in the sequence, it turns green.
If the typed letter is incorrect, it turns red. Cursor moves to next character regardless of if key typed was correct/incorrect. 
This feedback happens immediately as each key is pressed.
Highlight the characte the student should input in a light gray.
No traditional input text box is used; instead, letters update directly on the screen as part of a custom visual layout.
The next letter in the sequence should remain neutral (e.g., gray or black) until it is typed.
Ideally works with individual letters or whole words, progressing automatically.

LEVEL 1
Start with the Home Row (A S D F J K L ;)
Show this reminder to students: 
    Practice: Type the home row keys, focusing on keeping your fingers in the correct positions. 
    Focus: Don't look at the keyboard, and maintain focus on accuracy. 
Ask students to type character combinations of the home row - auto generate the combos so they are different each time. Combos can be in the following formats: (1) aad gfj kl; (2) aa jj kk ss (3) asdf jkl; ;lks asdf
Use ENTER key to submit the work, show the accuracy, then create another problem. 
Once a student has gotten 90% accuracy over 10 practices, they move to level 2.

LEVEL 2: Home row practice words. Select 10 words at random from the list of 26. Students must type 90% accuracy over all these 10 words to move to level 3. If they mess up a word, replace it with another word from the list that is not part of the original 10. Show each word individually.
